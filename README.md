# นักวาดมือฉมัง

แอปวาดรูปแบบ PWA สำหรับแท็บเล็ตกับปากกา ใช้งานออฟไลน์ได้ ผลงานเก็บอยู่ในเครื่องเท่านั้น

- เปิดใช้: https://zetsubo07.github.io/nakwad/
- สถานะ: กำลังสร้างรุ่น 1 (ขั้น M1 โครงโปรเจกต์)

## สำหรับนักพัฒนา

```bash
npm ci
npm run dev      # เปิดเซิร์ฟเวอร์ตอนพัฒนา
npm run check    # ตรวจโค้ด ตรวจชนิด ทดสอบ build และทดสอบในเบราว์เซอร์ (เหมือน CI)
```

ข้อความทุกคำในแอปอยู่ที่ `src/i18n/th.ts` และเรียกใช้ผ่าน `t("ชื่อ")`
